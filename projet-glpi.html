GLPI sur Debian

Gestion de parc et helpdesk relié à l'Active Directory

Déploiement de GLPI 11 sur un serveur Debian 13 dédié, publié en HTTPS. Les utilisateurs se connectent avec leur compte Active Directory et l'inventaire des postes remonte automatiquement grâce à GLPI Agent.

GLPI 11 Debian 13 LDAP Apache PHP 8.4 MariaDB
  • Installation de Debian 13 en mode serveur, adresse IP fixe, enregistrement DNS
  • Pile Apache 2.4, PHP-FPM 8.4 et MariaDB, base de données dédiée
  • Arborescence sécurisée : configuration et données hors de la racine web
  • Publication en HTTPS sur glpi.sisr.lan
  • Authentification Active Directory (LDAP) et attribution automatique des profils
  • Inventaire automatique des postes avec GLPI Agent
  • Sauvegarde et restauration, cahier de recette
  • Guide utilisateur pour les utilisateurs, techniciens et administrateurs
